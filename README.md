# map_generator

**Заявка:** Разработка генератора пиксельных карт игрового мира 

**Статус основной страницы:** зафиксировано

**Участники:**
Дробыш Дмитрий
Дьяков Лев
Убушаева Яна

**Описание:**

Создание ПО для процедурной генерации двумерных карт по случайному начальному ключу генерации (seed).
Предусмотреть генерацию карты высот, полей температуры и влажности, определение типов местности на основе этих данных. 
Реализовать размещение поселений на пригодных участках суши и построение дорог между выбранными парами поселений с учетом проходимости местности и перепадов высот. 
Обеспечить визуализацию полученной карты и сохранение результата в изображение.
1. Генерация карты высот, полей температуры и влажности. 
2. Обработка рельефа, определение типов местности и формирование изображения. 
3. Размещение поселений и построение дорожной сети. 

Города — условные значки на карте, без генерации внутренней застройки.
Дороги — маршруты между выбранными парами поселений.

**Алгоритмы:**

- шум Перлина
- шум Броуновский
- граф путей
- пороговая классификация
- сглаживание матрицы
- чанкование (квадрат/строка)


Команда запуска
```bash
./bin/map_generator --width 8192 --height 8192 --seed 47 --procs 8 --workers 8 --settlements 50 --min-distance 400   --pairs 4 --png map.png --debug-overlay --chunk-size 64 --smooth-passes 2 --temperature-mode latitude
```

## 2. Решения

| Объект / правило | Договорённость |
|---|---|
| Базовые данные | Сохраняем terrain.World: Width, Height, Seed, Elevation, Temperature, Moisture |
| Индексация | Плоские массивы, индекс y*Width+x; координаты объектов (x, y) |
| Диапазоны | Высота и температура: [-1, 1]; влажность: [0, 1] |
| Граница суши | Суша при Elevation >= SeaLevel; одинаковое правило во всех модулях |
| Сглаживание | Лучше запускать до расчёта температуры |
| Чанки | Глобальные координаты; размер чанка и число работников не меняют результат |
| Seed | Воспроизводимость всех этапов; отдельный поток случайности для размещения |
| Местность | Стартовый набор: вода, пляж, равнина, лес, пустыня, горы, снег |
| Свойства местности | это, наверное, в конфиг |
| Поселения | id и координаты; пригодность, минимальная дистанция, ограниченное число попыток |
| Дороги | Идентификаторы концов и список координат; стоимость местности и перепада высот |
| Поиск пути | A*, четыре направления; вода непроходима |
| Выбор пар | Предлагается два ближайших соседа в одной сухопутной области; дубликаты пар удаляются |
| Недоступные пары | Не зависать; возвращать информацию об отсутствии маршрута |
| Отрисовка | Местность → дороги → значки поселений |
| CSV | Дополнительная диагностика, не обязательный обмен между модулями |
| CLI | Расширяем существующий cmd/map_generator, не создаём второй CLI |
