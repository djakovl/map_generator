# map_generator

**Заявка:** Разработка генератора пиксельных карт игрового мира 
**Статус основной страницы:** зафиксировано
**Участники:**
Дробыш Дмитрий
Дьяков Лев
Убушаева Яна

**Описание:**
Создание ПО для процедурной генерации двумерных карт по случайному начальному ключу генерации (seed).
Предусмотреть генерацию карты высот, полей температуры и влажности, определение типов местности на основе этих данных. 
Реализовать размещение поселений на пригодных участках суши и построение дорог между выбранными парами поселений с учетом проходимости местности и перепадов высот. 
Обеспечить визуализацию полученной карты и сохранение результата в изображение.
1. Генерация карты высот, полей температуры и влажности. 
2. Обработка рельефа, определение типов местности и формирование изображения. 
3. Размещение поселений и построение дорожной сети. 

Города — условные значки на карте, без генерации внутренней застройки.
Дороги — маршруты между выбранными парами поселений.

**Алгоритмы:**
шум Перлина
шум Броуновский
граф путей
пороговая классификация
сглаживание матрицы
чанкование (квадрат/строка)
